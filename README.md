# AI Comic Book Generator 📖✨

**Een volledig geautomatiseerd systeem om complete stripboeken / manga te maken met AI.**

Dit project maakt het mogelijk om met één druk op de knop een heel stripboek (tot 100+ pagina’s) te genereren: van verhaalbedenking tot consistente afbeeldingen, PDF en opslag.

## Functies

- **Moderne Streamlit GUI** ("We gaan een strip maken!")
- Volledige **tabbed interface** voor verhaal, stijl, instellingen
- AI-ondersteunde generatie van verhaal, stijl en prompts
- Karakter-consistentie (met referentie-afbeeldingen)
- Live log / voortgangsmonitor
- Automatische opslag per pagina + volledige PDF
- Klaar voor serieproductie (meerdere boeken)
